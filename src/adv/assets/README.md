# 本地自制演出资源

本目录 SVG 均为阅读器原创程序绘制，按本项目 AGPL-3.0-only 许可证提供。无需网络服务、Unity 或额外字体。

- `communication-frame.svg`：480×340 通讯窗口边框。
- `noise.svg`：固定种子的噪点及扫描线，可按执行器时钟平移。
- `soft-mask.svg`：1024×1024 柔边遮罩，缺少 `Image/mask_*` 时使用。
- `slash.svg`：方向性斩击，可翻转与旋转。
- `particles.svg`：透明粒子纹理。

`RuntimeEffects.tsx` 另用 SVG 几何绘制冲击放射线、能量环、烟雾、雨、插入三角形；不需要生成几百张重复位图。生命周期和动画全部由执行器时间控制，回退/恢复时不会继续旧 CSS 动画。数值型 `bit_talk_*` 只能确认名称时采用中性粒子效果，不猜测其原版外观。诊断中始终标注替代资源与近似性质。

这些资源是功能性替代，不是原版资源的复制，也不代表与真机视觉一致。音频 cue、USM 内容、3D 和 FSM 图不能从命令名称重建，分别保留静音、可跳过影片占位或状态记录；可以用自定义 ZIP 的映射替换。
